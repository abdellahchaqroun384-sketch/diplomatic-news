# Diplomatic News — Static version

This folder is a standalone version of the Diplomatic News redesign using only HTML, CSS, and JavaScript. It includes the original logo, the complete editorial catalogue, theme switching, RTL Arabic mode, ticker, hash routing, search, article pages, mobile drawer, and newsletter confirmation.

## Run locally

```bash
python3 -m http.server 4174
```

Open `http://localhost:4174/` from inside this folder.

## Deploy to GitHub Pages

Upload the contents of this folder to a repository, enable **Settings → Pages → Deploy from branch**, and select the `main` branch and `/root` folder. The generated GitHub Pages URL is your public test link.

For Netlify or Vercel, drag and drop this folder or select it as the project root. No build command is required.
